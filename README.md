# 📖 Digital Memory Book & Anniversary Scrapbook

An interactive, editorial-style 3D digital memory book and anniversary website built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

## ✨ Features
- **Editorial Scrapbook Layouts:** Single photo, duo spreads, and trio polaroid/scrapbook arrangements.
- **Live Counter & Timeline:** Tracks time together down to the second and showcases chronological relationship milestones.
- **Live Moments / Media:** Support for photo cards, video clips, and modal lightboxes.
- **Background Music Player:** Ambient soundtrack integration with customizable audio controls.
- **Future Bucket List:** Checkable goals and dreams to achieve together.
- **Closing Letter & Envelope:** Heartwarming animated final message display.

## 🛠 Customization
All personal data is isolated in a single configuration file:
👉 Edit `src/data/anniversaryData.ts`:
- Change couple names (`coupleNames`)
- Set your relationship start date (`startDate`)
- Add your photos into `public/images/` and update references
- Customize milestones, bucket list items, and your closing letter!

## 🚀 Quick Start
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
